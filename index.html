🔍 The EDA Workflow

EDA = Exploratory Data Analysis

EDA is the systematic process of investigating your data before building any model. It's how you discover patterns, spot problems, and form hypotheses. Every data scientist does this FIRST.

1. Shape
df.shape, df.info() — How big? What types?
2. Summary
df.describe(), df.head() — Quick stats at a glance
3. Missing
df.isnull().sum(), sns.heatmap(df.isnull()) — Where are the holes?
4. Distributions
Histograms, KDE, box plots — How is each feature spread?
5. Relationships
Correlation heatmap, scatter plots, pairplot — How do features interact?
6. Target
groupby + target, countplots with hue — What predicts the outcome?
7. Insights
Write down 3-5 key findings. This guides your ML model later!

The Complete EDA Template (Copy This!)

# ═══════ COMPLETE EDA TEMPLATE ═══════ # 1. SHAPE & TYPES print("Shape:", df.shape) print(df.info()) # 2. QUICK SUMMARY print(df.describe()) print(df.head()) # 3. MISSING VALUES print(df.isnull().sum()) sns.heatmap(df.isnull(), cbar=True, yticklabels=False, cmap="viridis") plt.title("Missing Value Map") plt.show() # 4. DISTRIBUTIONS (one histogram per numeric column) df.hist(figsize=(12, 8), bins=20, edgecolor="black") plt.suptitle("Feature Distributions", y=1.02) plt.tight_layout() plt.show() # 5. CORRELATIONS plt.figure(figsize=(10, 8)) sns.heatmap(df.corr(), annot=True, cmap="coolwarm", center=0) plt.title("Correlation Matrix") plt.show() # 6. TARGET ANALYSIS for col in ["Sex", "Pclass", "SibSp"]: sns.countplot(x=col, hue="Survived", data=df) plt.title(f"Survival by {col}") plt.show() # 7. KEY INSIGHTS print(""" INSIGHTS: 1. Higher fare = higher survival (proxy for class) 5. Sex is the strongest predictor (correlation +0.54) """)
