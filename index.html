📊 What is a Dataset?

Think of it Like a Spreadsheet

A dataset is an organized collection of data stored in rows and columns — exactly like a table or spreadsheet you'd see in Google Sheets or Excel.

📄
Each ROW = one record (one person, one transaction, one event). In Titanic: each row = one passenger.
📊
Each COLUMN = one feature (one property or attribute). In Titanic: Name, Age, Gender, Ticket Class, etc.
🎯
One special column = the target/label — what you're trying to predict. In Titanic: "Survived" (0 = No, 1 = Yes).

📂 What is CSV? What is Excel?

CSV — The Universal Data Format

CSV stands for Comma-Separated Values. It's the simplest way to store a table — just a plain text file where each value is separated by a comma, and each line is a new row.

📄 What a CSV looks like inside
PassengerId,Survived,Pclass,Name,Sex,Age,Fare 1,0,3,"Braund, Mr. Owen",male,22,7.25 2,1,1,"Cumings, Mrs. John",female,38,71.28 3,1,3,"Heikkinen, Miss. Laina",female,26,7.92
Plain text — commas separate values. Opens in ANY text editor, Excel, Google Sheets, Python!

🧹 Cleaning the Titanic Data

Why Clean Data? — Garbage In, Garbage Out!

Real-world data is always messy. Our Titanic dataset has 3 problems we need to fix before analysis:

❓
Missing Values
Age: 177 missing (20%)
Cabin: 687 missing (77%!)
Embarked: 2 missing
🔤
Wrong Data Types
"Sex" is text — ML needs numbers!
"Embarked" is letters — need encoding
🗑️
Useless Columns
PassengerId: just a counter
Name: unique text (hard to use)
Ticket: random strings

Fix 1: Handle Missing Values

# Check what's missing print(df.isnull().sum()) print(f"\nAge missing: {df['Age'].isnull().sum()} out of {len(df)} ({df['Age'].isnull().mean()*100:.1f}%)") print(f"Cabin missing: {df['Cabin'].isnull().sum()} out of {len(df)} ({df['Cabin'].isnull().mean()*100:.1f}%)")
Age missing: 177 out of 891 (19.9%) Cabin missing: 687 out of 891 (77.1%)
Age → Fill with median (28)
# Fill Age with the median (middle value) df["Age"].fillna(df["Age"].median(), inplace=True) print("Age missing after fix:", df["Age"].isnull().sum()) # 0!
Why median not mean? Because mean is affected by outliers (that 80-year-old!). Median is safer.
Cabin → DROP the whole column
# 77% missing = too much to fill. Drop it! df.drop("Cabin", axis=1, inplace=True) print("Columns after drop:", list(df.columns))
Rule of thumb: If >50% of a column is missing, drop the whole column.
Embarked → Fill with mode (most common)
# Only 2 missing — fill with the most common port df["Embarked"].fillna(df["Embarked"].mode()[0], inplace=True) print("Embarked missing:", df["Embarked"].isnull().sum()) # 0!
Mode = most frequent value. Most passengers boarded at Southampton ("S").

Fix 2: Drop Useless Columns

# Remove columns that don't help analysis df.drop(["PassengerId", "Name", "Ticket"], axis=1, inplace=True) print("Remaining columns:", list(df.columns)) print("Shape:", df.shape)
Remaining columns: ['Survived', 'Pclass', 'Sex', 'Age', 'SibSp', 'Parch', 'Fare', 'Embarked'] Shape: (891, 8)
🧹 We went from 12 columns to 8! We dropped PassengerId (just a counter), Name (unique text), Ticket (random codes), and Cabin (77% missing). The remaining 8 columns are all useful for analysis.

Fix 3: Convert Text to Numbers (Encoding)

ML models need numbers, not text! We need to convert "Sex" and "Embarked".

# Method 1: Map (for binary columns like Sex) df["Sex"] = df["Sex"].map({"male": 0, "female": 1}) print("Sex column:\n", df["Sex"].head()) # Method 2: One-Hot Encoding (for multi-category columns) df = pd.get_dummies(df, columns=["Embarked"], drop_first=True) print("\nNew columns:", list(df.columns))
Sex column: 0 0 ← male 1 1 ← female 2 1 ← female 3 1 ← female 4 0 ← male New columns: ['Survived', 'Pclass', 'Sex', 'Age', 'SibSp', 'Parch', 'Fare', 'Embarked_Q', 'Embarked_S']
Before
Sex: "male", "female"
Embarked: "S", "C", "Q"
After
Sex: 0, 1
Embarked_Q: 0/1, Embarked_S: 0/1

🔍 Analyzing the Titanic Data

Technique 1: Value Counts — Who Survived?

value_counts() counts how many times each value appears. Perfect for categorical data!

# Overall survival print(df["Survived"].value_counts()) print(f"\nSurvival rate: {df['Survived'].mean()*100:.1f}%")
0 549 ← Died 1 342 ← Survived Survival rate: 38.4%
Died: 549 (61.6%)
Survived: 342 (38.4%)

Technique 2: GroupBy — Survival by Category

groupby() splits data into groups, applies a function, and combines results. The most powerful analysis tool in Pandas!

# Survival rate by gender print("By Gender:") print(df.groupby("Sex")["Survived"].mean() * 100) # Survival rate by class print("\nBy Class:") print(df.groupby("Pclass")["Survived"].mean() * 100)
By Gender: Sex 0 18.9% ← Male survival: only 18.9%! 1 74.2% ← Female survival: 74.2%! By Class: Pclass 1 63.0% ← 1st class: 63% survived 2 47.3% ← 2nd class: 47% 3 24.2% ← 3rd class: only 24%!
🔍 Key Findings!
👩
Women survived at 4× the rate of men (74% vs 19%) — "women and children first!" policy confirmed by data.
🎩
1st class survived at 2.6× the rate of 3rd class (63% vs 24%) — wealth = access to lifeboats.
